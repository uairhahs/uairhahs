## About me

- By day I work on data platforms, pipelines and cloud infrastructure (AWS, Snowflake, Python, SQL).
- After hours I build the small tools I wish already existed, mostly for the Linux and Windows desktop.
- Currently exploring MCP servers and local AI agents.

## Homelab

A small fleet run entirely as code, used as my DevOps playground:

- **Declarative everything:** NixOS flake across multiple hosts, one deploy script, encrypted secrets in the repo.
- **Orchestration:** k3s cluster with a GPU inference node that wakes on demand.
- **Ingress:** VPS relay over a WireGuard-based mesh, reverse proxy with private-by-default vhosts.
- **Storage and backup:** SnapRAID and mergerfs pool, nightly parity, offsite encrypted backups.
- **Observability:** Prometheus and Grafana dashboards, alerts pushed to my phone.
